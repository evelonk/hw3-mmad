# подборка вин

приложение для домашнего задания по логистической регрессии

## запуск

проверено с Python 3.13.15, версии библиотек указаны в requirements.txt

из папки wine_app:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

в windows окружение активируется командой `.venv\Scripts\activate`

после запуска нужно открыть адрес из терминала

## файлы и вкладки

- `app.py` — четыре вкладки: одно вино, метрики, пакетное предсказание и коэффициенты
- `model.joblib` — обученный пайплайн с масштабированием
- `config.json` — выбранный на валидации порог и порядок признаков
- `test.csv` — отложенная тестовая выборка с target
- `example.csv` — пример входного файла без target

приложение загружает готовую модель и не обучает ее. общий ползунок в сайдбаре меняет порог во всех вкладках, результаты пакетного предсказания можно скачать

входной CSV должен содержать столбцы:

```text
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

все значения числовые, is_red равен 0 для белого вина и 1 для красного. при нехватке обязательных столбцов приложение показывает сообщение об ошибке

## кэширование

для модели используется `st.cache_resource`: он сохраняет один общий объект модели на сервере. для таблицы и вероятностей используется `st.cache_data`: он кэширует данные и возвращает их копии, чтобы изменения в одном запуске не портили остальные

без декоратора `joblib.load` заново читал бы модель с диска при каждом движении слайдера. вероятности на тесте не зависят от порога, поэтому они тоже кэшируются, а при смене порога заново считаются только метки и метрики. аргумент `_model` исключен из хэширования
